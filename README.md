# CEO Stat

Закрытый кабинет статистики торговых роботов.

## Стек

- Laravel 12
- Livewire 4
- Tailwind CSS 4
- MySQL 8
- Laravel Sanctum (будущий API MT4/MT5)

## Первый запуск

### Docker Desktop (рекомендуется для Windows)

```bash
git clone https://github.com/marketingromanov-tech/ceo-stat.git
cd ceo-stat
git switch agent/calendar-robots-accounts
docker compose up --build -d
```

После запуска откройте `http://localhost:8080`.

Демонстрационный вход: `admin@ceostat.local` / `ChangeMe123!`.

Остановить проект:

```bash
docker compose down
```

Полностью удалить локальную базу и начать заново:

```bash
docker compose down -v
```

### Без Docker

```bash
cp .env.example .env
composer install
php artisan key:generate
npm install
npm run build
php artisan migrate --seed
php artisan serve
```

Перед публикацией измените пароль демонстрационного администратора из `DatabaseSeeder`.

## Реализовано в первой версии

- защищённый вход и выход;
- роли `admin`, `operator`, `viewer`;
- модели и миграции роботов, торговых счетов и дневных результатов;
- защита от дублирования записей будущего MT4/MT5 API;
- журнал аудита;
- стартовый адаптивный экран статистики.

## Управление статистикой

- `/` — общий календарь с суммой результатов всех роботов;
- `/robots` — список и настройка торговых роботов;
- `/robots/{robot}` — счёт, показатели и календарь конкретного робота;
- каждому роботу соответствует ровно один торговый счёт;
- внутри дня хранится упорядоченная история отдельных операций, а календарь показывает их сумму;
- первая дата с результатом автоматически становится началом учёта робота;
- дни до начала учёта блокируются и не участвуют в индивидуальных или общих расчётах;
- день без поступлений фиксируется отдельной нулевой записью;
- роли `admin` и `operator` могут изменять данные, `viewer` работает в режиме просмотра.
- администратор создаёт пользователей и назначает наблюдателю один или несколько роботов;
- наблюдатель видит в сводке, списке и календарях только назначенных ему роботов;
- удаление пользователей и роботов доступно только администратору и подтверждается его паролем.

### Импорт результатов за июль 2026

После применения миграций импортируйте поступления робота `№1 - 20000$`:

```bash
docker compose exec app php artisan db:seed --class=July2026ResultsSeeder
```

Повторный запуск заменяет только ручные записи этого счёта за июль 2026 года
и не создаёт дубликаты. Учёт начинается 20 июля: более ранние дни заблокированы
и исключены из расчётов. Дни без поступлений после начала учёта сохраняются с
нулевым результатом.
